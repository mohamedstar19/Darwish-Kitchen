# Darwish Kitchen 🍲

تطبيق وصفات أكل بالعربي، بيشتغل على **أندرويد** و**آيفون** و**الويب** من نفس الكود (Expo + React Native).

## المميزات

- **زرار "حناكل إيه النهارده؟"**: تختار الوجبة (فطار / غداء / عشاء) ومنين نقترح (وصفاتي / من النت / الاتنين)، والتطبيق يقترح أكلة. الوجبة بتتحدد تلقائيًا حسب الوقت، ومش بيكرر نفس الاقتراح ورا بعضه.
- **وصفاتي**: عرض الوصفات، بحث بالاسم أو المكوّن، فلترة حسب الوجبة والمفضلة.
- **إضافة وتعديل وصفة بصورتها**: من الكاميرا أو معرض الصور، والصورة بتتصغّر وتتحفظ على الجهاز.
- **من النت**: بحث في وصفات موقع [TheMealDB](https://www.themealdb.com) (مجاني، بالإنجليزي)، مع حفظ أي وصفة في وصفاتك. الوصفات اللي فيها لحم خنزير أو كحول بتتخفي.
- 6 وصفات مصرية جاهزة للبداية، وضع ليلي، واتجاه عربي من اليمين للشمال.

البيانات بتتحفظ على الجهاز نفسه (مفيش سيرفر ولا حساب).

## تشغيل التطبيق

```bash
npm install
npm start          # امسح الـ QR بتطبيق Expo Go على الموبايل
npm run web        # نسخة الويب على الكمبيوتر
```

## نسخة الآيفون (ويب)

كل push على `main` بيبني نسخة الويب وينشرها على GitHub Pages:
`https://mohamedstar19.github.io/Darwish-Kitchen/`

أول مرة بس: من إعدادات الريبو → **Pages** → **Source** اختار **GitHub Actions**.

على الآيفون: افتح الرابط في Safari ← زرار المشاركة ← **Add to Home Screen**، وهيظهر كأيقونة تطبيق.

## بناء ملف APK / نسخة المتجر

```bash
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview      # ملف APK للتجربة
npx eas-cli@latest build -p ios --profile production       # محتاج حساب Apple Developer
```
