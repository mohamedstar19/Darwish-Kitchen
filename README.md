# Darwish Kitchen 🍲

تطبيق وصفات أكل بالعربي، بيشتغل على **أندرويد** و**آيفون** و**الويب** من نفس الكود (Expo + React Native).

## المميزات

- **زرار "حناكل إيه النهارده؟"**: تختار الوجبة (فطار / غداء / عشاء) ومنين نقترح (✨ ذكي / من التطبيق / من النت / الاتنين)، والتطبيق يقترح أكلة. الوجبة بتتحدد تلقائيًا حسب الوقت، ومش بيكرر نفس الاقتراح ورا بعضه. **الاقتراح الذكي** بيختار على ذوقك (اللي عجبك وقيّمته واللي شفته قريب) وعلى حسب اليوم والوقت، ويقولك ليه اختار الأكلة دي.
- **عندي في التلاجة… 🧊**: اكتب أو صوّر الحاجات اللي عندك، والذكاء الاصطناعي يقترح أكلات تعملها بيها، ويقولك لو ناقصك حاجة.
- **صوّر وصفة مكتوبة**: في شاشة إضافة وصفة، صوّر صفحة الكشكول أو الكارت أو سكرين شوت، والذكاء الاصطناعي يكتب الوصفة في الخانات وانت تراجعها.
- **الرئيسية**: سلايدر بأكلات ومشروبات **مطبخ درويش**، وزرار "حناكل إيه النهارده؟".
- **الشيفات (الفيد)**: وصفات بينشرها مستخدمين التطبيق بأسمائهم وصورهم، مع إعجاب وحفظ وبلاغ.
- **وصفاتي**: وصفاتك انت بس (اللي ضفتها أو حفظتها)، بأقسام **أكل** و**مشروبات صحية** و**عصائر**. وانت بتضيف وصفة تقدر تنشرها في الفيد.
- **وصفات درويش**: وصفات المطبخ الرسمية بأقسامها، والأدمن بيتحكم فيها.
- **مشروبات صحية وعصائر** جاهزة في وصفات درويش (ينسون، كركديه، شاي أخضر، جنزبيل، سموزي، برتقال، ليمون بالنعناع، مانجو، فراولة باللبن، جوافة باللبن).
- **إضافة وتعديل وصفة بصورتها**: من الكاميرا أو معرض الصور، والصورة بتتصغّر وتتحفظ على الجهاز.
- **من النت (بالذكاء الاصطناعي ✨)**: اكتب اسم أي أكلة بالعربي أو الإنجليزي، والذكاء الاصطناعي (Claude) يدوّر في مواقع طبخ كتير عربي وأجنبي ويجيب الوصفات مكتوبة بالعربي مع اسم الموقع ورابطه وصورته، وكمان نتايج من [TheMealDB](https://www.themealdb.com). الوصفات اللي فيها لحم خنزير أو كحول بتتخفي.
- **حسابي (الملف الشخصي)**: اسمك ونبذة ورقم الموبايل وصورتك الشخصية، وقوائم بالوصفات اللي **ضفتها** و**عجبتك** و**قيّمتها** (من ١ لـ ٥ نجوم) و**شفتها**.
- **نسخ احتياطي واسترجاع**: دخول برقم الموبايل وكود بيوصل على واتساب، بيرفع نسخة من وصفاتك وصورها وملفك وتقييماتك على السيرفر، وترجّعها على أي موبايل تاني. فيه كمان حذف الحساب.
- **لوحة التحكم** (`/admin`): الأدمن يضيف صور ووصفات درويش، ويراجع وصفات الشيفات (إخفاء/حذف، والمبلّغ عنها).
- **مراجعة الفيد بالذكاء الاصطناعي**: أي وصفة بتتنشر بيتراجع كلامها وصورتها؛ الإعلانات والحاجات المسيئة بتستخبى على طول، والحاجات اللي فيها شك بتظهر للأدمن تحت "الذكاء الاصطناعي علّم عليها".
- **صور بالذكاء الاصطناعي**: من لوحة التحكم، الذكاء الاصطناعي يدوّر على صور لوصفات درويش اللي من غير صورة في مواقع الصور المجانية بس (Unsplash و Pexels و Wikimedia Commons)، ويقيّمها. تختار "أنا أراجع" (تختار الصورة بنفسك) أو "ارفع على طول" (الصور اللي متأكد منها بتتحط لوحدها). اسم المصوّر والموقع بيظهروا تحت الصورة.
- وصفات مصرية ومشروبات وعصائر جاهزة للبداية، وضع ليلي، واتجاه عربي من اليمين للشمال.

كل البيانات بتتحفظ على الموبايل نفسه. سيرفر درويش (kitchen.darwish-tech.com) بيستخدم **بس** للنسخ الاحتياطي والاسترجاع، والتطبيق بيشتغل كامل من غيره.

## تشغيل التطبيق

```bash
npm install
npm start          # امسح الـ QR بتطبيق Expo Go على الموبايل
npm run web        # نسخة الويب على الكمبيوتر
```

## تفعيل البحث بالذكاء الاصطناعي

1. اعمل مفتاح API من [console.anthropic.com](https://console.anthropic.com) (محتاج كارت للدفع حسب الاستخدام).
2. على السيرفر: `sudo nano /opt/darwish-kitchen/otp.env` وحط المفتاح بعد `ANTHROPIC_API_KEY=` ثم `sudo -u kitchen pm2 restart kitchen`.
3. اختياري: `AI_DAILY_LIMIT=20` (عدد مرات استخدام الذكاء الاصطناعي لكل عميل في اليوم: البحث والتلاجة وقراءة الوصفة والاقتراح الذكي، والأدمن مالوش حد) و `AI_MODEL` لو حبيت موديل تاني.
4. نفس المفتاح بيشغّل كل مميزات الذكاء الاصطناعي، ومراجعة الفيد وصور الوصفات بتتحسب على السيرفر مش على العميل.

## السيرفر والدومين

- نسخة الويب ونسخة الآيفون: **https://kitchen.darwish-tech.com**
- سيرفر النسخ الاحتياطي على نفس السيرفر والدومين (`/api`)، والكود بتاعه في [`server/`](server/).

النشر بأمر واحد من جهازك: `bash deploy/update.sh <IP السيرفر>` — التفاصيل وإعداد Cloudflare في [`deploy/README.md`](deploy/README.md).

على الآيفون: افتح الرابط في Safari ← زرار المشاركة ← **Add to Home Screen**، وهيظهر كأيقونة تطبيق.

## بناء ملف APK / نسخة المتجر

```bash
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview      # ملف APK للتجربة
npx eas-cli@latest build -p ios --profile production       # محتاج حساب Apple Developer
```
